# Welcome

This is the documentation for every script from [Level Scripts](https://level-scripts.tebex.io/). Each page explains what the script does, how to install it, every config option, commands, items and how to change the texts.

## Before you start

Every Level Scripts resource runs on top of [lvl\_core](lvl_core.md). It is free and comes with every purchase. lvl\_core detects your framework, inventory, target, notifications, progress bar and text UI, so the scripts work on ESX, QBCore, Qbox and more without any changes.

1. Install [lvl\_core](lvl_core.md) first.
2. Then follow the page of the script you bought.

New here? Read [Installation](getting-started/installation.md).
