# Welcome

Documentation for every [Level Scripts](https://level-scripts.tebex.io/) resource.

1. Install [lvl\_core](lvl_core/README.md), it is free and every script needs it.
2. Follow the page of your script.

New here? Start with [Installation](getting-started/installation.md).

## Scripts

| Script | Type | What it does |
| --- | --- | --- |
| [lvl\_dealership](paid-scripts/lvl_dealership/README.md) | Paid | Car, boat and air dealerships with showroom, test drives, financing, used car lot, company management and stock delivery trucks |
| [lvl\_motel](paid-scripts/lvl_motel/README.md) | Paid | Motel rooms with rent, shared keys, stash, wardrobe and police raids |
| [lvl\_rccar](paid-scripts/lvl_rccar/README.md) | Paid | Remote controlled cars with camera, microphone, antenna and battery |
| [lvl\_scoreboard](free-scripts/lvl_scoreboard/README.md) | Free | Player list with Discord avatars, job counts and illegal activity availability |
| [lvl\_backpack](free-scripts/lvl_backpack/README.md) | Free | Bags from the clothing menu add inventory slots and weight |
| [lvl\_drugsell](free-scripts/lvl_drugsell/README.md) | Free | Drug selling to NPCs, delivery customers and player vending machines, with levels |
| [lvl\_evidencebag](free-scripts/lvl_evidencebag/README.md) | Free | Police seal a suspect's items into a labeled evidence bag |
| [lvl\_fingerprint](free-scripts/lvl_fingerprint/README.md) | Free | Police fingerprint scanner that shows the identity of a player |
| [lvl\_illegalusb](free-scripts/lvl_illegalusb/README.md) | Free | Hack a USB, fight the guards and crack the crate for loot |
