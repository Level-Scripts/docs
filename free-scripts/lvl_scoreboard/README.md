# lvl\_scoreboard

[Get it on Tebex](https://level-scripts.tebex.io/package/scoreboard) | [Discord](https://www.discord.gg/UKqwhpjczw)

## Features

* Player list with ID, job and ping
* Discord avatars, names and role icons
* Job counts
* Illegal activities by police online
* Search by name or ID
* Bot token stays on the server

## Requirements

| Resource                                                          |                        |
| ----------------------------------------------------------------- | ---------------------- |
| [lvl\_core](../../lvl_core/)                                      | required               |
| [ox\_lib](https://github.com/overextended/ox_lib/releases/latest) | required               |
| Framework | ESX Legacy, QBCore, Qbox, ND Core, ox\_core or standalone |

The framework is detected automatically, you can set it in [lvl\_core configuration](../../lvl_core/configuration.md).
