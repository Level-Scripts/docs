# lvl\_carplay

[Buy on Tebex](https://level-scripts.tebex.io/) | [Discord](https://www.discord.gg/UKqwhpjczw)

## Features

* Synced music from YouTube and Spotify links, the whole car hears it
* Music heard outside the car, louder with open doors, windows or roof
* 25 GTA radio stations with logos
* Playlists saved on the server, shared by code
* Navigation map, destination shared with passengers
* Saved places and the nearest gas station, mechanic, hospital and more
* Vehicle controls: windows, doors, hood, trunk, lights, indicators, lock, roof, tyres
* Autopilot by speed limits and cruise control with presets
* Personal volume and streamer mode
