# Usage

## Commands and controls

| Command / key | What it does |
| --- | --- |
| `F7` | Opens CarPlay in a vehicle (rebindable in FiveM key bindings) |
| `/carplay` | Same as `F7` |
| `/carvolume 0-100` | Your personal car music volume, saved per player |
| `/streamermode` | xSound streamer mode, mutes all music for you |

## Apps

| App | Use |
| --- | --- |
| Music | Search, paste a YouTube or Spotify link, queue, repeat, volume |
| Radio | GTA radio stations |
| Playlists | Save playlists, share them by code |
| Map | Drag, zoom, click to set the destination |
| Places | Saved places and the nearest gas station, mechanic, hospital... |
| Vehicle | Windows, doors, hood, trunk, lights, indicators, lock, roof, tyres |
| Drive | Autopilot and cruise control |

Only the driver controls the vehicle, autopilot and cruise control. Passengers can roll their own window and use the music.
